Aby uruchomić pobieracz, należy otworzyć plik YtDownloader.exe. Po jego uruchomieniu pojawi się okno terminala, a po chwili w domyślnej przeglądarce otworzy się strona aplikacji.

Pobrane filmy są domyślnie zapisywane w folderze:

..\YtDownloader\app\downloads

Lokalizację zapisu można oczywiście w razie potrzeby zmienić.

Zaleca się również co jakiś czas aktualizować silnik pobierania za pomocą przycisku „Update Downloader”, aby zapewnić prawidłowe działanie aplikacji.
